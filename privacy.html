プライバシーポリシー

最終更新: 2026年10月29日

Grimoire（以下「本アプリ」）は、メモ・リンク・画像をカードにしてボードに並べるデスクトップアプリです。 本ポリシーは、本アプリが扱う情報と、その扱い方を説明します。

1. 手元の PC に保存する情報

ボード・カード・画像などのデータは、あなたの PC 上の保存先フォルダに保存します。 開発者がこれらのデータを受け取ることはありません。

2. Google アカウントのデータ（Google ドライブ同期を使う場合のみ）

同期は任意の機能です。使う場合、本アプリは次の権限を求めます。

  • アプリデータ（drive.appdata）: あなたの Google ドライブ内の、本アプリ専用の隠し領域に、ボードのデータを保存・読み込みします。 ほかのファイルは見えません。
  • メールアドレス（userinfo.email）: どのアカウントで接続しているかを、本アプリの設定画面に表示するために使います。
  • ファイルの読み取り（drive.readonly、取り込み機能を使う場合のみ）: あなたの Google ドライブの Grimoire_Inbox フォルダにあるファイルを読み、ボードに取り込みます。 それ以外のファイルは読みません。また、ファイルを変更・削除しません。

これらのデータは、あなたの PC 上の本アプリと Google のサーバーとの間で直接やり取りされます。 開発者のサーバーを経由せず、開発者が受け取ることも、第三者に提供・販売することも、広告に使うこともありません。 ログインの情報（トークン）は、あなたの PC 上にだけ保存します。

本アプリによる Google API から受け取った情報の利用と転送は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に従います。

3. 更新の確認

本アプリは、新しい版があるかを確かめるために、配布用のサーバーから更新情報のファイルを取得します。 このとき、あなたのデータやアカウントの情報は送りません。 配布用のサーバーは、一般的な Web サーバーと同じく、アクセスの記録（IP アドレスなど）を一時的に残すことがあります。

4. 埋め込みの表示

カードに YouTube などのリンクを置くと、その内容を表示するために、各サービスから直接読み込みます。 その通信には各サービスのプライバシーポリシーが適用されます。

5. データの削除

  • 手元のデータは、本アプリの保存先フォルダを削除すれば消えます。
  • Google ドライブ上のデータは、本アプリの設定画面でログアウトしたうえで、Google ドライブの 「設定 → アプリを管理 → Grimoire → 隠しアプリデータを削除」で消せます。
  • 本アプリへのアクセス権は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

6. 変更

本ポリシーを変更するときは、このページを更新し、最終更新日を改めます。

7. お問い合わせ

GitHub の Issues からご連絡ください。

Privacy Policy (English summary)

  • Your boards, cards and images are stored on your own computer. The developer does not receive them.
  • Google Drive sync is optional. If you use it, Grimoire requests drive.appdata (to store your boards in the app's hidden data folder in your own Google Drive), userinfo.email (to show which account is connected), and, only if you use the import feature, drive.readonly (to read files in your Grimoire_Inbox folder; Grimoire never changes or deletes them).
  • This data moves directly between the app on your computer and Google. It is not sent to the developer, sold, shared with third parties, or used for advertising. Sign-in tokens are stored only on your computer.
  • Grimoire's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Update checks download an update description file from the distribution server without sending your data or account information; the server may keep standard access logs (such as IP addresses) for a limited time.
  • You can delete synced data from Google Drive (Settings → Manage apps → Grimoire → Delete hidden app data) and revoke access at any time from your Google Account's third-party access page.
